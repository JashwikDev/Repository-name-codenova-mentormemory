# MentorMemory AI

MentorMemory AI is an AI tutor that remembers how a student learns.

Built by Team CodeNova for HackWithHyderabad 3.0.

## Problem
Normal AI tutors forget previous conversations and learning preferences.

## Solution
MentorMemory AI uses Hindsight persistent memory to remember:
- student weaknesses
- preferred explanation style
- previous mistakes
- topics already learned
- learning history

The recalled memory is then used to personalize future answers.

## Tech Stack
- Python
- Streamlit
- Groq
- GPT-OSS 120B
- Hindsight
